# Dev-View-for-ML-Kit
Upload an image, and Dev View runs it through ML Kit's OCR, then displays the image together with ML Kit's raw output in a scrollable library. See exactly how ML Kit handles an image and plan programatic parsing according to expected outputs.

For Android
